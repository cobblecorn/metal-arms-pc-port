Profile name: **100 Percent**. Solo profile version 12; co-op file version 1.

All 42 campaign missions completed, all 14 shipped PvP maps unlocked, all 104
hidden chips and 39 available time bonus chips collected. Enables the campaign
and 100-percent completion flags and the Original Concept Movie bonus. Time
records are generated below the authored bonus targets; kill/washer statistics
are zero. Uses the native level-unlock inventory templates for each mission,
including restricted inventories for special-character/puzzle missions.

matching completed co-op campaign, and never installs settings.ini. Co-op partners
continue to use the port's existing owner-progress synchronization.

Extract and run **Install Save.cmd**, then select **100 Percent** and **Replay**.
The installer honors MA_PORT_SAVE_DIR, supports an explicit -SaveRoot, checks both
source files before writing, rejects an active game, and backs up existing files
with this profile name before replacement. Other saves/settings are preserved.
README.txt also covers manual installation and restoration.
